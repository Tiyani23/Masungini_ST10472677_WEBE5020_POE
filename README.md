Hope Hands Community Foundation Website

About the Project

This project is a website developed for the Hope Hands Community Foundation, a non-profit organisation established in 2019 to support disadvantaged families through food relief, youth development, and community outreach programmes across Gauteng.

The website provides information about the organisation, its programmes, volunteer opportunities, and ways for people to get involved and support the foundation.

Mission

To empower vulnerable communities by providing education, food assistance, and opportunities that improve quality of life.

Vision

To create stronger communities where every individual has access to education, support, and equal opportunities.

Website Goals

The main goals of the website are to:

* Recruit volunteers.
* Increase donations.
* Promote community events.
* Raise awareness about the foundation.
* Share success stories.

Target Audience

The website is designed for:

* Volunteers
* Donors
* Corporate sponsors
* Community members
* Government organisations
* Youth

Website Pages

The website contains the following pages:

* Home – Introduces visitors to Hope Hands Community Foundation.
* About – Provides information about the organisation, its mission and vision.
* Programmes – Provides information about the programmes and community initiatives offered by the foundation.
* Volunteer – Provides information for people who are interested in volunteering.
* Contact – Provides contact information and a way for visitors to get in touch with the foundation.

Technologies Used

* HTML5
* GitHub
* Visual Studio Code

Project Objectives

The website aims to make it easier for visitors to learn about Hope Hands Community Foundation, discover its programmes, become volunteers, support the organisation, and stay informed about its community activities.
