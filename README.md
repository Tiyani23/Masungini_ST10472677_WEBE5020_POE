Hope Hands Community Foundation Website

1 Project Overview

The Hope Hands Community Foundation website is designed to provide information about the organisation and the support it offers to disadvantaged families across Gauteng

The foundation focuses on education, food relief, youth development and community outreach programmes

The website allows visitors to learn about the organisation, explore its programmes, find volunteering opportunities and contact the foundation

2 Website Objectives

The main objectives of the website are to:

* Introduce Hope Hands Community Foundation
* Share information about the organisation’s mission and vision
* Display the different community programmes offered
* Encourage people to volunteer and support the foundation
* Allow visitors to send enquiries and general messages
* Make information easy to access on different devices

3 Feedback From Part 2 and Improvements Made

Feedback from Part 2 was considered when making improvements to the website

The following improvements were made:

* Updated the CSS to make the website visually better

These changes were made to improve the quality, appearance and usability of the website

4 Technologies Used

The following technologies were used to develop the website:

* HTML5: Used to create the structure and content of the website
* CSS3: Used to style the website and improve its visual appearance
* JavaScript: Used to add interactive features and improve user experience

5 Website Pages

Page	Description
Home	Introduces the foundation and highlights its main activities
About Us	Provides information about the foundation, its mission and vision
Programmes	Displays the different programmes offered by the foundation
Volunteer	Provides information and a form for people interested in volunteering
Contact	Allows visitors to contact the foundation
Enquiry	Allows visitors to submit questions about the foundation and its services

6 Website Features

The website includes:

* Navigation menu to access different pages
* Responsive layout for different screen sizes
* Contact and enquiry forms
* Interactive JavaScript features
* Search functionality to help visitors find information
* Google Maps location on the contact page
* Images and information about the foundation’s programmes
* SEO elements such as page titles and meta descriptions

7 Responsive Design

CSS media queries are used to improve the website’s appearance on different screen sizes, including desktop computers, tablets and mobile phones

The layout is adjusted to make navigation, images, text and forms easier to use on smaller screens

8 SEO Improvements

Search Engine Optimisation (SEO) techniques were included to improve the website’s visibility and accessibility

These include:

* Adding unique page titles
* Adding meta descriptions to the website pages
* Using appropriate headings
* Including relevant keywords in the website content
* Adding descriptive alternative text to images
* Improving mobile responsiveness
* Including internal links between website pages

9 Project Folder Structure

The project contains the following main files:

* index.html – Home page
* about.html – About Us page
* programmes.html – Programmes page
* volunteer.html – Volunteer page
* contact.html – Contact page
* enquiry.html – Enquiry page
* style.css – Website styling
* script.js – JavaScript functionality
* images/ – Folder containing website images
